# Лабораторная работа №2. Классификация. Нейронные сети
Датасет: Heart Failure Clinical Records (цель `DEATH_EVENT`).

* `lab2_classification.ipynb` — отчёт (код + пояснения + результаты)
* `heart_failure_clinical_records_dataset.csv` — данные
* `logs/` — логи TensorBoard (`tensorboard --logdir logs`)
